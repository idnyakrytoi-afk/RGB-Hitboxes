# RGB Hitboxes

**RGB Hitboxes** is a lightweight, client-side Minecraft mod that adds smooth, animated rainbow colors to entity hitbox outlines.

It enhances the vanilla **F3+B** hitbox display with vibrant RGB effects while keeping the original debugging functionality intact.

## Features

- 🌈 **Animated RGB Colors** — Smooth, continuously changing rainbow outlines.
- 🎨 **Vanilla Style** — Preserves the original hitbox shapes and debug information.
- ⚡ **Lightweight** — A simple visual enhancement without unnecessary features.
- 🎮 **Client-Side** — Designed to work entirely on the client.
- 🔥 **Automatic Effects** — No additional keybinds required. Just press F3+B.

## Compatibility

- **Minecraft:** 1.21.11
- **Mod Loader:** Fabric
- **Side:** Client

## How to Use

1. Install the mod using Fabric.
2. Launch Minecraft.
3. Press **F3+B** to enable hitboxes.
4. Enjoy animated RGB hitbox outlines!

*Keep your hitboxes vanilla. Make their colors RGB.*
